# Assets originales (sin procesar)

Packs descargados tal cual vienen del proveedor. Esta carpeta tiene un `.gdignore`,
asi que Godot no la escanea ni la incluye en los exports.

Para usar un asset: extraerlo y copiar solo los archivos que se necesiten a
`assets/sprites/` (o la carpeta que corresponda), donde si los importa el editor.
